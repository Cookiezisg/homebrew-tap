# Homebrew tap for Anselm

```bash
brew install --cask Cookiezisg/tap/anselm
```

The cask installs the signed and notarized macOS build from the
[Anselm releases](https://github.com/Cookiezisg/Anselm/releases). It is bumped automatically a
few hours after each release; the app also updates itself through Sparkle.
